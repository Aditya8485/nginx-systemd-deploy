# Debug 502 Bad Gateway

A 502 from Nginx usually indicates upstream trouble. Compare:

```bash
sudo nginx -t
sudo tail -n 50 /var/log/nginx/error.log
sudo systemctl status demo-api --no-pager
sudo journalctl -u demo-api -n 80 --no-pager
ss -lntp | grep ':8000'
curl -i http://127.0.0.1:8000/health
```

Check `proxy_pass` URL, service `ExecStart`, environment packages, working directory, file permissions and resource limits. Restarting without finding the cause often hides recurring failures.
